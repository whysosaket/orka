# README graphics

These looping animated WebPs come from [the Orka website](https://tryorka.ai/), captured on November 6, 2026:

- `orka-overview@2x.webp`: one complete cycle of the live hero's Rive animations, showing Claude Code creating a skill, Orka receiving it, and Codex using it. Captured at a 1440 × 1300 browser viewport with a 2× device scale factor and motion enabled. The 1400 × 882 product illustration is captured at 2800 × 1764 pixels and encoded as lossless WebP at 30 fps without resizing.
- `product-tour@2x.webp`: the site's [2880 × 1800 screen-transition video](https://tryorka.ai/rive/screen-transitions.mp4?v=retina-copper), rendered at 1920 × 1200 with Lanczos scaling and encoded as lossless WebP at 30 fps. It moves through memories, skills, and session handoffs.

Both animations loop automatically and are stored locally so the README can play them without the website's scripts or a video player.
