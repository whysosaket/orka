# Settings state audit

Implementation audit updated after the Settings recovery fixes, November 7, 2026. Covers all six Settings destinations, navigation, dialogs, service changes, and scope changes. This is not a new Figma comparison or proof of every runtime failure.

All eight reported gaps and four approved behavior decisions are implemented. Fixed marks this change; Handled marks an existing path. No design decisions remain pending from this chart. Ordinary drafts are not persisted across restart.

## Verification and limits

Browser tests use the synthetic native bridge. API concurrency checks use real isolated PostgreSQL in cloud and self-hosted modes. Native Cmd+Q, window close, Stay, Discard, restart, and profile conflict/save were verified in an isolated macOS test app. Dock Quit and system shutdown were not exercised. Real OS Login Items, physical multi-Mac sync, and production deployment are outside this verification.

- Chromium: 56 Settings, recovery, and Agentation tests passed.
- WebKit: the same 56 tests passed.
- Native Rust: 195 passed; 8 existing ignored tests.
- API: profile concurrency and compatibility integration passed in cloud and self-hosted modes.
- Profile editing needs `profile.conditionalSave: 1`; older services remain readable but require an API update for editing. API 0.5.3 was deployed on November 8, 2026 with migration 011: all four production project members had email values after the backfill. Both members' emails were verified in the native Settings verification app against production. This does not establish production acceptance of the other Settings behaviors.
- Native acceptance passed: Cmd+Q and Cmd+W show the guard; Stay preserves the draft; Discard quits; restart restores the confirmed name. Shared profile comparison and the reviewed save passed against the isolated API.
